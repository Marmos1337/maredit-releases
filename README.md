# MarEdit

Локальный видеоредактор для **Apple Silicon и macOS 26.2 или новее**: запись экрана, монтаж, оформление, анимированные субтитры, озвучка и локальные AI-инструменты. Русский интерфейс включён по умолчанию; английский доступен через меню языка.

[Скачать актуальный PKG](https://github.com/Marmos1337/maredit-releases/releases/latest) · [Установка и обновление](INSTALL.md) · [Функции и примеры](FEATURE-GUIDE.md) · [Ограничения](KNOWN-LIMITATIONS.md) · [Лицензии](NOTICE.md)

Установщик заменяет приложение в `/Applications/MarEdit.app`. Python и зависимости AI входят в приложение. Необязательный речевой набор занимает **10,23 ГБ**: загрузите его в установщике или позже через **MarEdit → Модели ИИ…**. Интернет нужен для загрузки моделей; обработка выполняется локально. Ручной монтаж и экспорт работают без моделей.

Новые проекты сохраняются как `.marmos`. Последнее оформление запоминается для следующих проектов без обязательного сохранения текущего проекта. Содержимое и таймлайн при этом не копируются.

Приложение подписано ad-hoc; PKG не подписан Developer ID Installer и не нотариализован Apple. Установка на отдельном чистом Mac не подтверждена. Проверенные сценарии конкретной версии и её SHA-256 приведены на странице выпуска.

Репозиторий содержит установщики и пользовательскую документацию. Исходники и материалы сборки хранятся в отдельном приватном репозитории. Личные проекты, профили и записи не публикуются.
